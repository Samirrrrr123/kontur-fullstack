# Контур

Учебный блог со статьями и новостями. Можно публиковать свои посты, оставлять комментарии и ставить лайки. Есть фильтры по темам, популярные материалы и светлая/тёмная тема.

## Стек

React, TypeScript, Vite, Axios, Zustand. Сервер — Node.js и Express. Вход через JWT, пароли хешируются bcrypt.

Локально данные сохраняются в SQLite. Для PostgreSQL подготовлен `docker-compose.yml`.

## Запуск

Нужен Node.js 22 или новее. После скачивания запустить `Install.cmd`, затем `Start.cmd`.

Или через терминал:

```sh
npm install
npm run build
npm start
```

Сайт: http://127.0.0.1:3000. Окно сервера должно оставаться открытым. При повторном запуске достаточно `Start.cmd`.
